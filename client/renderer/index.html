    Use the Pi as an extra monitor

    Picking your main screen mirrors it. To extend your desktop onto the Pi, Windows needs a virtual display to extend onto:

    1. Install the free Virtual Display Driver.
    2. In Settings → System → Display, choose Extend these displays and set the new display to the Pi's resolution.
    3. Click Refresh, pick the new screen and press Start sharing.
