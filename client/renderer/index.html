    Use the Pi as an extra monitor

    Choosing your main screen mirrors it. To extend your desktop onto the Pi instead, Windows needs a virtual display to extend onto:

    1. Install the free Virtual Display Driver.
    2. In Settings, System, Display, choose Extend these displays and set the new display to the Pi's resolution.
    3. Refresh the list here, pick the new screen and start sharing.
