    Use the Pi as an extra monitor

    Picking your main screen mirrors it. To extend your desktop onto the Pi like a second monitor, Windows needs a virtual display to extend onto:

    1. Install the free, open-source Virtual Display Driver (one-time setup).
    2. Open Windows Settings → System → Display, choose Extend these displays, and set the new display's resolution to match the Pi.
    3. Click Refresh, pick the new screen here, and press Start sharing.

    Then drag windows onto it, just like a real monitor. Your mouse shows on the Pi when it's on that screen.
